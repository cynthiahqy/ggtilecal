# 10 Overlapping Events

A set of 10 demo events where Events 6,7,8 and 9 overlap, with
placeholder details generated using the
[zoo](https://emilhvitfeldt.github.io/emoji/reference/zoo.html) and
[ipsum](http://pkg.garrickadenbuie.com/lorem/reference/ipsum.md).

## Usage

``` r
demo_events_overlap
```

## Format

A data frame with 10 (event) rows and 6 columns:

- event_id:

  Unique identifier for the event.

- title:

  Plaeholder title for the event

- start:

  Start date of the event.

- end:

  End date of the event.

- duration:

  Duration of the event in days.

- emoji:

  Emoji representing the event theme or type.

- details:

  Loreum Ipsum placeholder details of the event.
