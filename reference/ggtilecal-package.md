# ggtilecal: Create static (and interactive) overview calendars using ggplot2

Creates tile-based calendar layouts using ggplot2 facets and tiles.
Calculates calendar layout positioning variables, and generates
customisable ggplot2 calendars for specified time periods and calendar
units.
