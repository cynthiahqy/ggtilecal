  A modified version of

## Helper Functions

Functions for reshaping event data, generating calendar units, and
calculating layout variables

- [`reframe_events()`](https://cynthiahqy.github.io/ggtilecal/reference/reframe_events.md)
  **\[experimental\]** : Reframe event intervals to calendar units
- [`make_empty_units()`](https://cynthiahqy.github.io/ggtilecal/reference/make_empty_units.md)
  : Make empty sequence of calendar units between specified date range
- [`make_empty_month_days()`](https://cynthiahqy.github.io/ggtilecal/reference/make_empty_month_days.md)
  : Make padding day unit entries for specified months
- [`fill_missing_units()`](https://cynthiahqy.github.io/ggtilecal/reference/fill_missing_units.md)
  : Fill out long format event table with missing dates
- [`calc_calendar_vars()`](https://cynthiahqy.github.io/ggtilecal/reference/calc_calendar_vars.md)
  : Calculate variables for calendar layout
- [`label_yearmonth()`](https://cynthiahqy.github.io/ggtilecal/reference/label_yearmonth.md)
  : Label month facets
